WHAT YOU CAN DO

  • SETTINGS

    One panel opens from any skin's right-click menu. No file editing.

  • ALIGNMENT

    Left or right per skin, so a skin can sit on either screen edge.

  • DETAILS

    Choose what stays visible and what waits for hover.

  • LIGHT AND DARK

    Follows the same tokens in both. Accent follows your Windows colour.

  • TOOLTIPS

    On or off, one switch per skin.

  • ONE DESIGN SYSTEM

    Colours, type and motion live in one theme file. Change a value and refresh.

INSTALL

Needs Rainmeter on Windows. From the repo folder in PowerShell:

powershell -ExecutionPolicy Bypass -File tools\install.ps1

The installer links the repo into your Skins folder, creates your settings files, installs the plugins the skins need, loads the Control-Plaine layout and opens Settings, which starts a short first-time setup. The README covers the manual route.
